1- Utilice el archivo llamado comandos para gestionar las operaciones, y crear las imágenes correspondientes.
2- Una vez creadas las imágenes utilice los comandos para correr los contenedores, solo corra uno a la vez.
3- Use el comando de Revisar usuario para checar el usuario que se esta utilizando.
4- Habra el navegador y navegue a las rutas agregadas al final del archivo comandos.
5- Antes de abrir el segundo contenedor debe detener el primero utilizando los comandos dados en el archivo comandos.
6- Ahora puede correr el segundo contenedor que es el de la app segura, y repita los paso 3 y 4.
